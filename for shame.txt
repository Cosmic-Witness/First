Comparing how training choices affect model diversity
Yes, that is a sensible plan, and much better than another giant search. It has one weak point, though.

Averaging helps most when the models make different mistakes. If you take a model and train it a bit more, it stays very close to the original, so the averaged result will be only slightly better. You would see more gain if the extra training changes the models, for example by using different random seeds, different augmentations, or different parts of the data.

There are two ways to average. You can average the predictions of the models, which always works. Or you can average the weights themselves, which gives one model and works well when all the models were fine-tuned from the same starting checkpoint. This is often called a model soup, and it is cheap because you only run one model at the end.
